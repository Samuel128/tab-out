03 / HOW IT WORKS

How these numbers arrive

The page combines a server query, an on-demand local scan, and a private Markdown archive. Opening it never uploads Token data.

01

Install TokenCollector separately

First install and configure the TokenCollector skill on this computer. Tab Out does not install it or manage your company network connection.

~/.codex/skills/TokenCollector
02

Show cache, then refresh in background

The saved Markdown history renders first. Tab Out then runs TokenCollector's local completed-day scan and read-only server query in the background, replacing the view when fresh data arrives. Scheduled upload remains unchanged.

--query-local + --query-wide
03

Merge and display local history

Server totals stay authoritative. Local totals fill missing dates or raise stale values without double-counting, and their source remains marked until a later scheduled upload is processed. The merged result updates the Markdown archive.
